Job Summary

The NET Developer Co-op Student will assist with the development, maintenance, and support of web applications and software solutions using .NET technologies. Working alongside the development team, the student will gain hands-on experience with modern web development, cloud technologies, APIs, databases, and DevOps practices while contributing to application enhancements, testing, troubleshooting, and documentation.

Duties and Responsibilities

• Assist with developing and maintaining web applications using ASP.NET Core MVC / .NET Core.

• Support and maintain legacy .NET Framework MVC applications.

• Build and improve modern user interfaces using Lit Components and modern UI frameworks.

• Assist with developing REST APIs and database-driven applications.

• Gain hands-on experience with AWS services, including ECS and ECR.

• Use Azure DevOps for source control, CI/CD, and development workflows.

• Assist with testing, troubleshooting, documentation, and application improvements.

Skills and Qualifications

• Currently enrolled in a University or College program related to Computer Science, Software Development, Web Development, Information Technology, or a related field.

• Basic knowledge of C# and .NET / .NET Core.

• Familiarity with ASP.NET MVC and/or .NET Framework MVC.

• Basic knowledge of HTML, CSS (Bootstrap), JavaScript (JQuery) and TypeScript.

• Familiarity with modern UI frameworks (Angular, Vue, React) and Lit Components is an asset.

• Familiarity with AWS (ECS, ECR, S3, SES).

• Familiarity with Azure DevOps and Git.

• Basic understanding of REST APIs and relational databases.

• Strong willingness to learn and work collaboratively in a team.
