Job Summary

The City of Mississauga is seeking an experienced Application Developer to support the modernization of the Property Tax Management system. The successful candidate will design, build, test, deploy, and support cloud-native web applications that replace legacy Oracle Forms and reports. We are looking for a pragmatic application developer who can translate complex taxation workflows, legacy PL/SQL logic, forms, and reports into maintainable digital products. The candidate should be comfortable working across frontends, backend, data, integration, security, and DevOps. You collaborate effectively with business analysts, architects, database specialists, security teams, infrastructure teams, vendors, and municipal partners, and you can balance modernization goals with business continuity and data integrity.

The role operates in a hybrid work environment, with office presence required at Mississauga City Hall, 300 City Centre Drive, Mississauga.

Duties and Responsibilities

The Successful Candidate will:

Develop accessible, responsive web interfaces using TypeScript and a modern frontend framework such as React or Angular.

Develop and maintain Java services, APIs, business rules, integrations, and batch-processing components supporting property-tax workflows.

Build reusable front-end components and RESTful APIs that follow API-first, modular and testable design principles.

Develop containerized services on Amazon ECS and AWS Fargate, using Amazon S3 and DynamoDB for state management and asynchronous job processing

Design and implement RESTful APIs and reusable services that integrate frontend applications, workflow orchestration, databases, reporting components, and external systems.

Implement asynchronous and scheduled processing for reports, calculations, file generation, data transformation, and other long-running jobs.

Build batch, scheduled-report and event-driven workflows using AWS Step Functions and container-based job processing.

Create and maintain automated unit, integration, API, end-to-end, regression, performance, and security tests.

Participate in the progressive migration of forms and reports while supporting coexistence between the modern AWS platform and the legacy environment.

Apply role-based access control using Azure AD federation, AWS Cognito, JWT claims, and application-level authorization.

Contribute to DevOps CI/CD pipelines, including static application security testing (SAST), code coverage, and pull-request review workflows.

Protect data and secrets through TLS, encryption at rest, least-privilege IAM roles, AWS KMS, and AWS Secrets Manager.

Investigate and resolve application defects, failed workflows, performance issues, integration errors, and production incidents.

Produce technical designs, interface specifications, data mappings, runbooks, deployment instructions, test evidence, and support documentation.

Estimate development effort, identify delivery risks, and contribute to sprint planning, backlog refinement, release planning, and technical governance.

Follow the City’s SDLC and AI-SDLC standards: author specifications and steering files, review all AI-generated output, and stay accountable for submitted code.

Provide operational support, knowledge transfer, and continuous enhancement for TXM applications and services.

Skills and Qualifications

Post-secondary degree in Computer Science, Software Engineering, Information Technology, or a related discipline.

Minimum 3-5 years of experience developing enterprise applications.

Experience developing applications using Java and object-oriented programming principles.

Experience with modern JavaScript/TypeScript development frameworks such as React, Angular, or Vue.

Experience developing and integrating RESTful APIs and web services.

Experience with AWS services like ECS Fargate, S3, Aurora DB, ALB, Cloudfront etc.

Experience with relational databases and SQL preferably Postgre SQL.

Experience with cloud-based application development (AWS preferred).

Experience with source control, automated testing, and CI/CD practices.

Knowledge of application security principles and secure coding practices.

Strong analytical, problem-solving, and communication skills.

Ability to work independently and collaboratively within a team environment.
